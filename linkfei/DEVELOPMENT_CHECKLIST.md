# LinkFei 六项能力开发清单

## 1. 存储抽象

- [x] 定义统一 `Storage` 基类与实现检查
- [x] 业务层只依赖存储方法，不直接操作 SQL
- [x] 将机器人入口、会话服务、检索逻辑与飞书文档逻辑分离
- [x] 保留未来切换 PostgreSQL 或远程存储的接口边界

验收：缺失必要方法的存储实现会在启动时失败；机器人入口不保存内存 Map。

## 2. SQLite 持久化

- [x] 使用 Node.js 内置 `node:sqlite`，不新增原生第三方依赖
- [x] 自动建库、建表和索引
- [x] 开启 WAL、外键、忙等待和事务
- [x] 持久保存会话、消息、摘要、记忆、知识和任务
- [x] 数据库路径可通过 `LINKFEI_DB_PATH` 配置
- [x] 数据目录禁止提交

验收：关闭并重新打开数据库后，历史消息仍可读取。

## 3. 事件去重与文档任务

- [x] 使用飞书 `messageId` 作为持久化幂等键
- [x] 成功、失败和处理中事件均不会重复消费
- [x] 文档任务记录生成、写入、完成、失败和中断状态
- [x] 相同消息不会重复创建文档
- [x] 启动时恢复并标记中断任务
- [x] `/tasks` 可查看最近任务

验收：同一飞书消息投递两次，只回复一次；重启会标记未完成任务。

## 4. 会话摘要与上下文预算

- [x] 按字符预算选择最近消息，不再机械固定 12 条
- [x] 超过阈值后调用 Flash 模型压缩旧消息
- [x] 摘要与最近原文分开持久化
- [x] 摘要失败不影响主回复和原始消息
- [x] 阈值、保留量和预算均支持环境变量

验收：超过测试阈值后旧消息被摘要，近期窗口仍保留。

## 5. 显式长期记忆

- [x] `/remember` 保存用户明确要求记住的内容
- [x] `/memory` 列出本人的记忆
- [x] `/forget ID` 和 `/forget all` 删除记忆
- [x] `/new`、`/reset` 不删除长期记忆
- [x] 按飞书 `senderId` 隔离个人记忆
- [x] 群聊禁止管理或注入个人长期记忆，避免私人信息泄露
- [x] 只把与当前问题相关的记忆注入提示

验收：不同发送者不能查看或检索彼此的个人记忆。

## 6. 本地知识库与检索

- [x] `/kb add` 导入带标题的文本知识
- [x] `/kb list`、`/kb search`、`/kb delete` 管理知识
- [x] 长文本自动分块
- [x] 中文二元词和英文词元向量化
- [x] 使用稀疏向量余弦相似度及精确匹配加权排序
- [x] 私聊按用户隔离、群聊按群共享
- [x] 正常问答自动注入最相关知识片段

验收：相关知识排序在无关内容之前，零相关内容被过滤，不同范围互不检索。

## 综合质量门槛

- [x] 保持原有问答、`/pro`、`/doc`、`/reset` 和配置兼容
- [x] API Key 不进入日志、测试快照或数据库
- [x] 新增存储、检索、摘要、隔离和入口幂等测试
- [x] 使用真实 `.env` 完成 DeepSeek 连通性验证
- [x] 使用真实 DeepSeek 完成自动摘要并重开临时数据库验证恢复
- [x] 使用真实飞书 API 创建、写入并回读验收文档
- [x] 使用飞书 Markdown 转块接口写入标题、列表、代码、表格和公式
- [x] 开通并核验 `docx:document.block:convert` 应用身份权限
- [x] 开通并核验 `space:document:delete`，验收后自动清理测试文档
- [x] 移除飞书转换结果中表格只读字段 `merge_info`，通过代码块、表格与富文本真实验收
- [x] 验证 `$...$` 与 `$$...$$` 生成原生 `equation` 元素
- [x] 使用已有飞书登录态从网页打开验收文档并核对正文
- [x] 启动机器人并确认飞书长连接
- [x] 开通并核验私聊事件权限 `im:message.p2p_msg:readonly`
- [x] 在飞书分别验证记忆、知识库、重启恢复和文档任务
